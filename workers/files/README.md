# Воркер файлов: files.khryuchik.com

Через воркер Cloudflare скачиваются купленные книги (по ссылке из письма и из кабинета) и бесплатные материалы раздела развлечений. Код лежит рядом, в этой папке.

## Как это работает

1. Покупатель открывает ссылку на сайте: `/api/downloads/…`, `/api/account/downloads/…` или `/api/entertainment/…/download`.
2. Сайт проверяет доступ и перенаправляет браузер (302) на `files.khryuchik.com/<bucket>/<key>?name=…&type=…&exp=…&sig=…`.
3. Воркер проверяет подпись (HMAC-SHA256, общий секрет) и срок, а затем отдаёт файл из R2 потоком: с именем файла, поддержкой докачки (Range) и без лимитов Netlify.

Подписанная ссылка живёт 10 минут (`SIGNED_FILE_LINK_TTL_SECONDS`). Срок проверяется только в момент начала скачивания, поэтому начатая загрузка не обрывается. Ссылки в письмах и кнопки на сайте ведут на сайт, а не на воркер, и продолжают работать как раньше.

## Настройки

| Где                   | Переменная             | Значение                      |
| --------------------- | ---------------------- | ----------------------------- |
| Netlify, `.env.local` | `FILES_BASE_URL`       | `https://files.khryuchik.com` |
| Netlify, `.env.local` | `FILES_SIGNING_SECRET` | общий секрет                  |
| Воркер (secret)       | `FILES_SIGNING_SECRET` | тот же секрет                 |

Если на сайте нет хотя бы одной из двух переменных, сайт отдаёт файлы сам, как раньше. Если секреты на сайте и в воркере расходятся, воркер отвечает 403.

## Команды

- `npm run files:login` — один раз войти в Cloudflare. Нужен тот аккаунт, в котором лежат бакеты и домен.
- `npm run files:deploy` — выложить воркер. Пуш в git воркер не обновляет.
- `npm run files:secret` — задать или сменить секрет воркера.

Чтобы сменить секрет, задайте новый в воркере и в Netlify, затем сделайте редеплой сайта. Ссылки, выданные за последние 10 минут, перестанут работать; повторный клик выдаст новую.
